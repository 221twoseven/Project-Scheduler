Staff

People are shared through SharePoint — every browser and teammate sees the same list. Names suggest from the company Team in Microsoft Teams; picking one fills the work email automatically. Check the departments each person works in, and add out-of-office ranges to flag their bars.

Clients

Clients are shared through SharePoint — the Client field on every project suggests from this list. Alias is the 2–3 letter job-code prefix (job codes themselves are still assigned in the Excel master for now). This browser can't reach the list — edits stay local until it's back.

Your projects past their install date

These projects list you as Project Manager and their install dates have passed. Confirm each one: mark it complete if the job has ended, or open it to extend the schedule.

Print Preview

Prints the current lens exactly as arranged on screen — collapse projects or departments first to control what's included. Tip: the Week or Month zoom fits longer ranges on a page.

Meeting Sheet

One row per project, grouped by PM and sorted by deadline. Respects the Status filter — set it first to control what prints. The Notes column stays blank for handwriting. Print on 11×17 landscape; the header repeats on every page.

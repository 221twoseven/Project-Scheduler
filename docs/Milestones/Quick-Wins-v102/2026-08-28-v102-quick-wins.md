# 2026-08-28 — v1.0.2: the quick-wins batch (objectives 5, 8, 12, 13)

The first release of the v2.0.0 track (`docs/TODO.md` §3, "quick wins"): four owner
objectives plus a copy fix found during the docs sweep. App version bumped
**v1.0.1 → v1.0.2** (patch: fixes and styling, no new features).

## What changed

- **(Obj 5) A window resize no longer closes the phase form.** With a phase or
  subtask selected (its form in the bottom dock), resizing the browser used to drop
  the selection and bounce the dock up to the project pane — the page repaint reset
  `PP_SEL` unconditionally. A `PP_KEEP` repaint (resize, background poll, autosave)
  now carries the selection through: the form, breadcrumb tail and selection ring
  all survive. Bonus fix for free: a background poll landing mid-selection no longer
  kicks the user off their phase either — same root cause.
- **(Obj 8) A blank calendar click that dismisses the edit popover keeps the
  selection.** Clicking empty calendar space with the edit popover open used to also
  deselect — which collapses the expanded phase (REV84 ties expansion to selection).
  The popover dismissal now follows the same rule as the add-menu dismissal: the
  press that closes a layer spends itself on that; the *next* blank click deselects
  and collapses. Applies to both Gantt and calendar modes (one shared handler).
  **REVISED same day by the owner → v1.0.3:** on the calendar, blank space never
  deselects at all — the expanded phase persists until its **parent band is clicked
  a second time** (that toggle is the collapse; a re-clicked *subtask* band just
  reopens its editor, and `ev.detail` keeps double-click-rename intact). Esc, the
  breadcrumb and the × still peel the selection; the Gantt keeps its empty-canvas
  deselect. Design-Language §6 amended.
- **(Obj 12) The black bar mellowed.** The toolbar's near-black ink gradient became
  a soft slate-navy pair (`#2A3850 → #202C41`), with a softer edge and shadow, and
  the small text lifted for legibility: secondary labels (`SHOP TIMELINE`, the
  version pill, the search placeholder) `#5E7292 → #8CA0BF` (~5.7:1 on the new
  fill), button text to `rgba(255,255,255,.9)`, the Lock-dates label to `.62`.
  `--ink`/`--ink-2` keep their values (they also serve text and `labelColor()`);
  `--chrome-line` lifted `#232F42 → #3A4A66`. Design-Language §2 updated.
- **(Obj 13) Vivid months shows the month colour uninterrupted.** In Vivid, weekend
  and holiday columns no longer paint grey strips: the main timeline and project
  Gantt hide their overlay columns, and the project calendar's weekend cells take
  the month tint inline like weekdays (the hatch rule is gone). Quiet mode — the
  default — keeps its full weekend treatment, and the Day/2-Day date header still
  marks weekends in both modes. Design-Language §2.4 updated.
- **Stale "Settings" strings fixed** (carried loose end, found 2026-08-28): five
  empty-state hints and a comment still pointed at the Settings menu retired in
  REV95 — they now say Resources.
- **Test runner: self-skipped suites are now visible.** `tests/run.js` prints a
  `SKIP` summary line naming every suite that feature-sniffed itself off — closing
  the audit-pass ledger entry ("a typo'd sniff could silently disable a suite
  forever"). Gate fired because this change touched the runner (registering the new
  suite).

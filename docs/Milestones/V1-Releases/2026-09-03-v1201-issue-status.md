# v1.20.1 — Issue status, TD standalone, undo-arrow shape

**Date:** 2026-09-03 · **Version:** v1.20.1 · **Branch:** development

Three follow-ups the owner asked for right after merging v1.20.0 (PR #35).

## What changed

- **Resolved reports.** ⚠ column spec delivered for `ShopTimeline_Feedback`:
  internal name exactly **`status`**, type **Single line of text**, value `resolved`
  or empty (empty/absent = open — the staff-flag tristate convention). Owner ruling:
  reports are **marked resolved, never removed** — a resolved report leaves the
  public Open Issues list but stays on the dev-only Bug Reports page with a
  RESOLVED chip and a Reopen button. Until the column exists, everything reads
  open and the first Mark-resolved shows a clear error toast (the v1.15.2 rule).
- **Technical Design is standalone** (like Project Management): the `othoffice`
  "Other (Office)" bucket is *retired*, not deleted — hidden from the department
  checklist, task modal, inspector dropdown and right-click spare-dept menu, but a
  legacy row using it still renders everywhere. Ledgered in TODO §7.
- **Undo/redo icons** redrawn to the owner's reference: broad top arc with a solid
  triangular head (verified visually via the local preview stub).
- Hardening found on the way: a stale/slow feedback fetch can no longer overpaint a
  newer Open Issues list (paint-generation guard).
